Not sure which Mac you have? Open the Apple menu, choose About This Mac, and look for Chip (Apple Silicon) or Processor (Intel).

Or install it with one line.

Paste it into Terminal (Mac) or PowerShell (Windows). It also clears the “unsigned app” prompt for you.

macOS curl -fsSL https://mclauncher.crooli.com/install.sh | bash
Windows irm https://mclauncher.crooli.com/install.ps1 | iex

One line: it downloads the latest version from GitHub, checks it, puts it in Applications (Mac) or runs the installer (Windows), and opens it. Read the Mac script or the Windows one first if you like.

Opening it the first time.

The app isn’t signed by Apple or Microsoft yet, so both may ask before opening it once.

On a Mac

Easiest: use the one-line install above. Or drag the app into Applications, and if macOS says it’s damaged or can’t be opened, paste this into Terminal once:

xattr -cr "/Applications/Crooli MC Launcher.app"

On Windows

Run the installer. If a blue SmartScreen window appears, choose More info, then Run anyway. Updates install themselves after that.
